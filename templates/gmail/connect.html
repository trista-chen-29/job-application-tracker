Gmail → Google Sheet

Pull recruiter confirmation mail and fill your existing tracker (internships / newgrad). Status keeps moving as OA, interview, offer, and rejection emails arrive.

Recommended: sheet plugin

This lives on your spreadsheet, like an add-on. No extra website to keep running.

  1. Open Trista Internship Tracker.
  2. Extensions → Apps Script. Replace the default file with sheets-addon/Code.gs and add appsscript.json from this repo.
  3. Save, go back to the sheet, reload. Use Tracker → Sync Gmail now, then Install hourly sync.
  4. Approve Gmail + Sheets when Google asks. Use the same Google account as this inbox.

It fills the first empty Company row (so your dropdown templates stay put) and will not overwrite Offer with Rejected.
